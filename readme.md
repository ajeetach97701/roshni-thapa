# Roshani Thapa — Portfolio

A responsive, static portfolio built with plain HTML, CSS, and JavaScript. No build step or runtime dependencies are required. The site is ready for Cloudflare Pages on the Free plan.

## Preview locally

Open `index.html` in a browser, or serve this directory with any static file server.

## Deploy to Cloudflare Pages

1. Push this repository to GitHub or GitLab.
2. In Cloudflare, create a Pages project and connect the repository.
3. Choose **None** as the framework preset, leave the build command empty, and set the build output directory to `/`.
4. Deploy. The HTML, CSS, JavaScript, SVG, PDF, and `_headers` file are static assets; no Workers or paid services are required.

Cloudflare Pages direct upload can also publish the directory without connecting a Git repository.

## Replace the portrait placeholder

Replace `assets/profile-placeholder.svg` with Roshani’s portrait (or update the image source in `index.html`). The illustration is only a placeholder and does not depict the actual person.
